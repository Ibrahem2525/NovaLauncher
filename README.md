# NovaLauncher 🚀

A lightweight, blazing-fast Windows desktop launcher inspired by macOS Spotlight. Built with Python and PySide6, featuring a modern glassmorphic interface and native Windows Acrylic blur.

## ✨ Features
- **Instant Activation:** Toggle instantly using `Alt + Space`.
- **Zero Lag Indexing:** Background multithreading scans your Start Menu and Desktop shortcuts instantly.
- **Smart Utilities:** Built-in AST-safe calculator, direct system commands (`shutdown`, `taskmgr`, `lock`), and instant web/YouTube search.
- **Glassmorphic UI:** Smooth borderless pill design with native Windows 11 Acrylic blur.
- **Single-Instance:** Prevents duplicate processes automatically.

## 📥 How to Download & Use
1. Go to the **Releases** section on the right side of this repository.
2. Download the latest `nova_launcher.zip`.
3. Extract the ZIP file and run `nova_launcher.exe` (it runs quietly in the background).
4. Press `Alt + Space` anywhere on your screen to bring up the search bar and type away!
